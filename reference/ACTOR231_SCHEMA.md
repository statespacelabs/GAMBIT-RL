## Conventions and implementation details

- All indices are zero-based. Names are descriptive labels for the actual writes; the frozen manifest names groups rather than every scalar.
- actor231 is exactly the environment vector. The manifest’s composite_actor_input_dim=363 equals 231+132 policy-owned tactical/recurrent state; it does not describe 363 Unity sensor fields. Current navigator code consumes 231 observations and passes GRU hidden state separately.
- Positions/linear velocities/rays/memories use a yaw-only local frame: x right, y up, z forward. Angular-rate fields 3..5 are Euler-angle finite differences, not a rotated physical angular-velocity vector.
- Angles for radial probes: 0 degrees forward, 90 right, 180 back, 270 left. Torso and free-space sector 0 start forward. Hunt sector 0 instead starts at -180 degrees; it is not the same indexing convention.
- Ranges describe valid finite telemetry and ignore floating-point roundoff. All emitted values are dimensionless. u denotes a Unity length unit; frozen schema prose calls these metres, but an independent real-world unit calibration is not recorded.
- dt=max(Time.fixedDeltaTime, 0.0001). Fixed timestep is 0.02 s. History lengths 25 and 100 therefore span nominally 0.5 and 2 s after warmup.
- BuildObservation clears all 231 outputs first. Missing self/opponent/CharacterController returns an all-zero vector. The per-field miss/invalid defaults below describe normal component availability.
- Frozen actor normalizer is analytic_bounded_identity: mean 0/std 1 for every field, no fitted whitening. Unity supplies scaling/clipping. The inspected current inference adapter passes actor231 directly to the navigator; it does not apply another statistical normalizer. The JSON records the frozen per-index safety envelope, which is often wider than a field’s actual binary/nonnegative range.
- The source comment claiming hidden geometry is consulted only for LOS is incomplete: UpdateHuntCue also reads hidden geometry inside its permitted quantizer. Current exact visible-target features 193..201 are zero while hidden.
- StaticRay ignores trigger colliders and every collider with a PlayerBody ancestor, then takes the nearest remaining hit across all layers. “Static” names the helper; it does not test Unity isStatic, so non-player moving props can also be detected.
- Recent damage 12..15 and last heard 207..210 are populated by incoming-hit events with separate uniform angular jitter (±12 and ±18 degrees). Last heard is not a general footsteps/audio stream. An explicit false-heard-cue injection method exists for interventions; ordinary activation is not established.
- Memory valid flags do not expire when normalized age reaches 1. Last seen stores a world point but exposes only its stale position in the current observer frame; direction cues store event-time world directions. ResetMemory clears cue validity/history and previous command.
- Hunt cue refresh is at most 2 Hz (0.5 s). Dropout default 0.15 can be overridden by PHASE5_HUNT_CUE_DROPOUT. Optional minimum/maximum dropout-duration environment settings default 0 seconds. Exact hidden geometry is quantized before output; bins are held between refreshes.
- Hunt base bearing uses floor(repeat(angle+180, 360)/45). Bearing jitter is -1/0/+1 sector with probabilities 0.20/0.60/0.20. Distance bins use edges 4, 8, 16, 32; distance jitter is -1/0/+1 with probabilities 0.15/0.697/0.153 before clipping to 0..4 (two conditional RNG draws). Each valid cue has two one-hots, not a continuous target vector.
- Index 10 is a constant-zero reserve placeholder despite the group’s reserve-ammo description. Index 9 uses weapon CurrentAmmo/MaxAmmo; the restored weapon source returns equal constants. Sensor-source identity was checked across all 8 restored copies; bytecode-to-source reconstruction of every paper build remains UNKNOWN.
- Previous action 16..23 stores the preceding controller command. Shoot/reload/jump requests may be blocked by gameplay; these fields are not confirmed execution events.
- Collision history 28 counts any CollisionFlags, including ground contact; it is not specifically a wall-collision rate. Progress/stuck checks use 3D displacement and request thresholds, not NavMesh progress.
- Tactical flags 227..230 are deterministic sensor-derived cues, independent of both the historical TemporalExpertSelector and the diagnostic EIG opponent selector.
